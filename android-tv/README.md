# 红果短剧 TV 测试版 1.0

独立 Android 电视客户端，目标测试设备小米 S Pro L75MB-SP。最低 Android 5.0（API 21），通用 APK，不含 CPU 架构专用库。具体小米固件尚未实测。

## 首版功能

- 剧集目录、按名称搜索、分集列表。
- 系统播放器在线播放，原始比例显示竖屏视频。
- 遥控器方向键、确定和返回；暂停、前进/后退10秒、上一/下一集。
- 自动连播；到受限集数停止，不跳过。
- 本机观看记录和进度恢复，最多40部；不上传记录，不需要账号。

## 当前来源限制

内容读取 `hongguoduanju.com` 的公开网页。2026-10-13现场样本《首辅娇娘》共69集，公开入口仅前三集，公开MP4为360×640。电视大屏清晰度有限。本测试版不提供付费、登录或受限内容的访问。

搜索来源当前仅返回前10条，不提供虚假翻页；建议输入完整剧名。目录支持真实分页。可看范围、来源结构和网络条件可能改变；应用会显示错误并提供重试。

## 构建

需要 JDK 21、Android SDK Platform 36 / Build Tools 36.0.0、Python 3，以及 zip。

```sh
ANDROID_SDK_ROOT=/path/to/android-sdk TV_JAVA_HOME=/path/to/jdk sh build.sh
```

脚本直接使用 Android 官方 SDK 工具编译，APK 无第三方运行时依赖。首次生成独立测试签名，私钥与密码保存在 `.private/`，不得外传或加入源码包。保留此目录才能为同包名提供可覆盖安装的后续测试版本。公开 APK 仅含公钥证书；非 Google Play / 小米商店审核发行。

输出在 `dist/`。构建、签名和清单回执在 `build/`。既有 APK 会备份到 `build/previous-apks/`。

## 验证范围

数据解析21项、播放状态10项、记录5项断言通过；实网读取目录/搜索/分集，前三集公开MP4片段有效，第四集按公开可看范围拒绝。Ego Lite实际播放来源网站页和公开MP4，画面与时间推进通过。

Android 电视安装、遥控器完整路径、原生解码音画、自动连播与休眠唤醒仍需真机验证。浏览器通过不代表电视端通过。

复跑断言（需要一个 JVM 可用的 org.json 实现，例如 `com.vaadin.external.google:android-json:0.0.20131108.vaadin1`，不打入APK）：

```sh
TV_TEST_JSON_JAR=/path/to/android-json.jar sh test.sh
# 追加 --live 可检查当时来源网络；受来源可用性影响。
```
